Forensic Accounting & Investigation

  • Net Worth Theory:
    • Calculation: Gross Income = Increase in Net Worth + Personal Expenditure/Family Spending.
    • Adjustment: Cash hoarded from previous periods is subtracted from gross income.
  • Expenditure Theory:
    • Methodology: Compares total cash uses to total income to identify undisclosed/unreported funds.
    • Suitability: Most suitable when no books of accounts are maintained, records are inadequate, or the taxpayer is withholding records.
    • Exclusions: Ignores non-cash expenses like depreciation and amortization.
  • Investigation using Intelligence: Focuses heavily on behavioral and background analysis (e.g., evaluating educational background, family pressures, lifestyle spending, companions).
  • AICITSS Curriculum Focus: Core areas include Forensic Accounting and Fraud Detection, Digital Forensic and Cyber Security, and Data Analytics Tools.

3. Cyber Security & Digital Forensics

Threat Profiles & Attacks

  • Reconnaissance: Attack involving unauthorized discovery and mapping of systems, services, or vulnerabilities (e.g., port scans).
  • Spammer: An individual who sends large numbers of unsolicited bulk messages.
  • Phishing: Trickery to gain sensitive information by spoofing a legitimate source.
  • Vishing: A fraudulent phone call attempting to steal personal information (e.g., banking passwords/OTPs).
  • Phreaker: An individual who manipulates the phone network to cause it to perform unauthorized functions.
  • Viruses vs. Worms: Worms are self-replicating and spread standalone; viruses require a host file to attach to.
  • Zombie: A compromised computer/device within a botnet controlled remotely.
  • Denial of Service (DoS): An attack designed to saturate network links with spurious data, disabling services to intended users.
  • Cyber-squatting: Registering a domain name intending to profit from someone else's trademark.
  • Port Redirection: Attack using a compromised host to pass traffic through a firewall that would otherwise be dropped.

Industry Cyber Landscape

  • Ethical Hacking: Primary purpose is to identify system vulnerabilities proactively (White Hat).
  • Financial Sector Threats: Recognized globally by G7, G20 Finance Ministers, and CPMI at BIS.
  • Trending Attacks: Ransomware attacks, supply chain attacks, phishing, and insider threats.
  • Mobile Threats: A 2016 ITU/CGAP survey revealed 83% of Philippine, 56% of the Ghanaian and 27% of the Tanzanian mobile money users received fraudulent SMSs.

4. Microsoft Power BI & Power Query

Power BI Ecosystem

  • Common Workflow: Create a dataset in Power BI Desktop > Publish to Power BI Service > Share dashboards.
  • Power BI Desktop: Used to create datasets, visualizations, and reports.
  • Power BI Service: Used to schedule data refreshes (up to 8 refreshes per day), embed reports, and distribute apps.
  • Views in Desktop:
    • Report View: Used to create and arrange visual elements.
    • Data View: Inspect data in a tabular row/column format.
    • Model View: Define and manage table relationships.
  • Dataset vs. Dashboard: A dataset is the collection of data used to create visualizations. A dashboard is a single canvas containing tiles and widgets for quick insights.
  • Tiles: A rectangular box that holds an individual visual on a dashboard. (Pinning visuals adds them to a dashboard for quick access; pinning a full report page adds the entire page as a single tile).
  • Apps: A collection of dashboards/reports for distribution. Template apps publish pre-built content for customers.
  • Visuals & Formatting:
    • Format Pane: Customizes the appearance of visualizations.
    • Treemap: Best visual for showing hierarchical part-to-whole data.
    • DAX: Used to create dynamic titles for visuals.
    • AI Insights: Used to identify trends and anomalies in data.
  • Reading vs. Editing View: Reading view allows data viewing (consumer); Editing view allows data editing (designer).
  • Data Sources: Valid sources include Salesforce, Microsoft Azure, Excel, SQL Server, SharePoint, Web. (Adobe Illustrator files are NOT valid sources).

Power Query & M Language

  • Power Query Editor: Allows users to create reusable data transformations.
  • Lexical Structure: Defines valid texts in the M formula language.
  • Records: Sets of name-value pairs allowing names to be written without quotes.
  • Let Expressions: Primary role is to define auxiliary values for complex expressions.
  • Lazy Evaluation: Evaluation model where order is determined by dependencies (evaluated as needed).
  • Pure Functional: The programming paradigm the M formula language aims to achieve.
  • Parameter Values: Used in table functions primarily for naming output columns.
  • Equation Criteria: Used in table functions for equality comparisons with key selectors/comparers.

6. KNIME Analytics Platform

Nodes and Operations

  • Node Configuration: The method used to import data into a KNIME workflow.
  • Data Explorer: Computes descriptive statistics and overviews data.
  • Statistics: Computes univariate summary/descriptive statistics.
  • Chi-Square Test: Used for hypothesis testing.
  • Normalizer: Scales data for machine learning models.
  • Spark Executor: Performs distributed data processing.
  • Association Rule Learner: Used for association rule mining.
  • Variable Loop Start: Iterates over a range of variable values.
  • Workflow Executor: Allows workflows to be called as subroutines.

Machine Learning & Execution

  • Machine Learning Workflows: Predict future outcomes based on historical data.
  • Regression: Predicting numerical values or quantities.
  • Cross-Validation Loop: Assesses model generalization in machine learning.
  • Ensemble Learner: Combines multiple models for improved predictive performance.
  • K-Means: Node used for k-means clustering.
  • Model Writer: Used for model deployment (saving models).
  • Model Reader: Loads a trained machine learning model for predictions.
  • Workflow Execution: Generates results based on the workflow's logic.

User Interface & Structuring

  • Canvas Size: Adjusted to customize the appearance of the workflow editor.
  • Metanodes: Simplify complex workflows by grouping nodes together.
  • Components: Encapsulate reusable workflow segments.
  • Workflow Coach: Suggests next nodes based on usage patterns.
  • Common Visualizations: Scatter Plot (Musical composition is not a standard node).

7. Robotic Process Automation (RPA) & ERP Systems

RPA Libraries & Tools

  • Selenium: Web automation and web scraping in RPA.
  • SMTP: Email automation.
  • OS: File handling.
  • Pandas & NumPy: Data manipulation (Pandas) and fast array math/data analysis (NumPy) in RPA.
  • Automation Anywhere: Workflow orchestration in RPA.

  • OpenCV: Image processing.
  • Tesseract: Optical Character Recognition (OCR).
  • BeautifulSoup: Web scraping/HTML parsing.
  • Task Scheduler: Used for scheduling unattended RPA execution.

Enterprise ERP (Dynamics 365 & Oracle)

  • Auditing: Discipline focusing on ensuring the accuracy and reliability of financial records.
  • Limitation of Financial Data Analysis: Overfitting of models.
  • Oracle Fusion ERP: Financial Reporting Studio is the financial audit and reporting tool.
  • Periodic Financial Closing: Primary purpose is to generate annual financial statements.
  • Zero-Based Budgeting: Methodology that reverses traditional budgeting.
  • Three-Way Matching in AP: Matches vendor invoices with purchase orders and product receipts.

Dynamics 365 Finance Specifics

  • Revenue Recognition: Breaks down sales into multi-element lines.
  • Subscription Billing: Cannot be used simultaneously with revenue recognition.
  • Revenue Journal: Used to release scheduled revenue to actual revenue.
  • Financial Dimensions: Classified as Custom dimensions vs. Entity-backed dimensions.
  • Expense Planning: Must consider the organizational hierarchy.
  • Per Diem Rates: Determined heavily by the employee's travel destination.
  • Deposit Slips: Purpose is depositing checks and cash into a bank account.
